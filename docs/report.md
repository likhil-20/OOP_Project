# 1. Introduction

Managing enterprise IT incidents manually often leads to delayed responses, unstructured ticket routing, and broken Service Level Agreements (SLAs). The **I-ITSM (Intelligent IT Service Management)** system is a full-stack enterprise solution designed to automate incident reporting, streamline technician assignments using strategy patterns, handle SLA tracking with automated background escalation, and provide role-based dashboards for Employees, Technicians, and Administrators. Built using **React, Spring Boot, and PostgreSQL**, the system guarantees secure authentication, auditability, and efficient lifecycle management.

# 2. Features Implemented

* **Multi-Role Dashboards:** Tailored interfaces for Employees, Technicians, and Administrators.
* **Smart Assignment:** Supports skill-based and load-based technician assignment strategies.
* **Automated SLA Escalation:** Background scheduler that automatically raises priorities for breached incidents and notifies stakeholders.
* **Audit Trail & Notifications:** Comprehensive logging of all system state changes and real-time alerts.
